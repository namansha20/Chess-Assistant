## 1. OVERVIEW

Chess.com Game Review Assistant is a Chrome/Edge browser extension (Manifest V3) 
that automatically analyzes your Chess.com games and provides human-friendly 
coaching feedback.

### Key Features
- Automatic game detection on Chess.com
- Extracts PGN, player color, time control, and result
- Human coach-style analysis (no engine jargon)
- Pattern detection across multiple games
- Actionable improvement suggestions
- Game history tracking (50 games)
- Privacy-focused (all processing local)

### Technical Stack
- Manifest V3 (modern Chrome extension standard)
- Vanilla JavaScript (no frameworks)
- Chrome Storage API
- MutationObserver for DOM monitoring
- Heuristic-based chess analysis

### 3.2 Analysis Engine (background.js)

**Message Listener:**
```javascript
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.type === 'GAME_ENDED') {
    handleGameEnd(request.data)
      .then(analysis => sendResponse({ success: true, analysis }))
      .catch(error => sendResponse({ success: false, error }));
    return true; // Keep channel open
  }
});
```

**Analysis Pipeline:**
```
Game Data → Parse PGN → Analyze Moves → Identify Key Moments 
          → Detect Patterns → Generate Summary → Store Results
```

**Move Evaluation Logic:**

The extension uses heuristic patterns to evaluate moves:

1. **Early Queen Development** (moves 1-6)
   - If queen moves early → Mark as MISTAKE
   - Reason: "Makes queen a target"

2. **Moving Same Piece Twice** (moves 1-10)
   - If same piece moves multiple times → INACCURACY
   - Reason: "Wastes development time"

3. **Not Castling** (by move 15)
   - If king still in center → MISTAKE
   - Reason: "King vulnerable to attacks"

4. **Pawn Weaknesses** (early pawn advances)
   - If pawns advance without support → INACCURACY
   - Reason: "Creates weaknesses"

5. **Captures**
   - Generally marked as GOOD
   - Reason: "Winning material"

6. **Checks**
   - Early checks without follow-up → INACCURACY
   - Tactical checks → GOOD

**Pattern Detection:**
```javascript

- Hanging pieces (count blunders)

// Displays when pattern appears 2+ times
```

**Coach Summary Generation:**
```javascript
// Opening assessment (moves 1-10)
if (openingMistakes === 0) → "Solid opening"
else if (openingMistakes <= 2) → "Decent with room for improvement"
else → "Opening needs work"

// Middlegame assessment (moves 11-30)
if (middlegameErrors === 0) → "Excellent middlegame"
else if (middlegameErrors <= 2) → "Good with occasional oversights"
else → "Middlegame was challenging"

// Overall based on result
if (win) → "Congratulations! Keep building on what worked"
if (loss) → "Learn from mistakes, focus on patterns"
if (draw) → "Fair draw! Keep reducing mistakes"
```

## 4. INSTALLATION & RUNNING

### 4.1 Prerequisites
- Google Chrome (v88+) or Microsoft Edge (Chromium-based)
- Chess.com account (for testing)

### 4.2 Local Development Installation

**Step 1: Get the Code**
```bash
# Clone the repository
git clone https://github.com/namansha20/Chess-Assistant.git
cd Chess-Assistant

# Or download as ZIP and extract
```

**Step 2: Load in Chrome/Edge**

**For Chrome:**
1. Open Chrome browser
2. Navigate to: `chrome://extensions/`
3. Enable "Developer mode" (toggle in top-right corner)
4. Click "Load unpacked" button
5. Navigate to and select the `Chess-Assistant` folder
6. Extension should appear in the list as "Enabled"

**For Microsoft Edge:**
1. Open Edge browser
2. Navigate to: `edge://extensions/`
3. Enable "Developer mode" (toggle in left sidebar)
4. Click "Load unpacked" button
5. Navigate to and select the `Chess-Assistant` folder
6. Extension should appear in the list as "Enabled"

**Step 3: Verify Installation**
- Look for the Chess Coach icon (♟️) in your browser toolbar
- If not visible, click the puzzle piece icon and pin the extension
- Extension status should show "Enabled"

**Step 4: Grant Permissions**
- Extension will request permission to access Chess.com
- Click "Allow" when prompted

### 4.3 Testing the Extension

**Quick Test:**
1. Go to Chess.com
2. Play a game (or use "Play Computer" for quick testing)
3. Complete the game (win, lose, or resign)
4. Wait for notification: "♟️ Game analysis ready!"
5. Click the extension icon in toolbar
6. View your personalized analysis

**Console Debugging:**
- Open DevTools (F12) → Console tab
- Look for: "Chess Coach: Content script loaded"
- After game ends: "Chess Coach: Game over detected!"

### 4.4 Validation Scripts

```bash
# Install npm (if not already installed)
npm install

# Run validation tests
npm test

# This runs:
# - JavaScript syntax validation (node -c)
# - JSON structure validation (manifest.json)
```

### 4.5 File Permissions

Ensure all files have read permissions:
```bash
# Linux/Mac
chmod 644 *.js *.json *.html *.css *.md
chmod 644 icons/*

# Windows: No action needed (default permissions work)
```

## 7. TROUBLESHOOTING

### 7.1 Common Installation Issues

**Issue: Extension doesn't load**
Solution:
- Check all files are present
- Verify manifest.json is valid JSON
- Check console for errors (F12)
- Try reloading extension

**Issue: Icon not showing**
Solution:
- Pin extension (click puzzle piece icon)
- Check icon files exist in icons/ folder
- Verify icon paths in manifest.json

**Issue: No game detection**
Solution:
- Open Chess.com
- Check console: "Chess Coach: Content script loaded"
- Ensure you're on a game page
- Refresh page if needed

### 7.2 Development Issues

**Issue: Code changes not reflecting**
Solution:
- Click "Reload" in chrome://extensions/
- Or remove and re-add extension
- Clear browser cache (Ctrl+Shift+Delete)

**Issue: Permission errors**
Solution:
- Check manifest.json permissions
- Ensure host_permissions includes chess.com
- Re-install extension after changes

### 7.3 Store Submission Issues

**Issue: ZIP file too large**
Solution:
- Exclude documentation (.md files)
- Exclude development files (package.json)
- Exclude .git folder
- Should be under 10MB

**Issue: Manifest validation errors**
Solution:
- Validate JSON syntax
- Check Manifest V3 compliance
- Ensure all required fields present
- Use: npm run validate

**Issue: Privacy policy required**
Solution:
- Add privacy policy to description
- Host policy on GitHub
- Include in manifest.json if needed

### 7.4 Post-Publication Issues

**Issue: Extension not appearing in search**
Solution:
- Wait 24-48 hours after publication
- Improve SEO: use keywords in description
- Get reviews and ratings

**Issue: Low user engagement**
Solution:
- Add better screenshots
- Improve description
- Create demo video
- Share on social media
