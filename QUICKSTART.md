# Quick Start Guide

## 🚀 5-Minute Setup

### 1. Install Extension
```
1. Download or clone this repository
2. Open Chrome → chrome://extensions/
3. Enable "Developer mode" (top-right)
4. Click "Load unpacked"
5. Select the Chess-Assistant folder
```

### 2. Play a Game
```
1. Go to Chess.com
2. Play any game (any time control)
3. Finish the game
4. See notification: "♟️ Game analysis ready!"
```

### 3. View Analysis
```
1. Click the Chess Coach icon in toolbar
2. Read your personalized feedback
3. Review key moments
4. Check focus areas
```

## 📊 Understanding Your Analysis

### Move Quality

| Icon | Type | Meaning | Example |
|------|------|---------|---------|
| 💥 | **Blunder** | Critical mistake | Hanging your queen |
| ⚠️ | **Mistake** | Significant error | Early queen development |
| ≈ | **Inaccuracy** | Suboptimal move | Moving same piece twice |
| ✓ | **Good** | Solid move | Castling early |

### Coach Sections

1. **Game Summary**
   - Your color, time control, result
   - Date and time played

2. **Coach's Analysis**
   - Opening assessment
   - Middlegame evaluation
   - Overall feedback
   - Strengths you showed
   - Areas to improve

3. **Key Moments**
   - Your biggest mistakes
   - Why they were bad
   - What you should have done
   - FEN position to review

4. **Recurring Patterns**
   - Mistakes you make often
   - How many times you've done it
   - Specific fix for each pattern

5. **Focus Areas**
   - Top 3 priorities
   - Actionable next steps
   - Specific practice advice

## 🔍 Common Questions

### "Why does it say 'PGN extraction pending'?"
The extension is still working on getting the moves. Refresh the popup in a few seconds.

### "I don't see any analysis"
Make sure:
- You're on Chess.com (not Lichess)
- The game fully ended (modal appeared)
- You clicked the extension icon after the game ended

### "What's a FEN?"
FEN (Forsyth-Edwards Notation) describes a chess position. You can copy it to any chess board viewer to see the exact position where you made a mistake.

### "Are patterns accurate?"
They track your actual moves across games. The more games you play, the more accurate pattern detection becomes.

### "Can I see my improvement over time?"
Yes! Check game history and count how often you make the same mistake. Frequency should decrease over time.

## 💡 Pro Tips

### Focus Strategy
```
Game 1-5: Learn what your patterns are
Game 6-10: Focus on fixing ONE pattern
Game 11-20: Track improvement, add second pattern
Game 21+: Maintain fixes, refine technique
```

### Quick Checks Before Each Move
```
1. Is my piece safe here?
2. Can I be captured?
3. Am I giving something away?
4. What's my opponent's threat?
5. Does this improve my position?
```

### Opening Checklist
```
□ Control center (e4/d4 or e5/d5)
□ Develop knights (Nf3, Nc3)
□ Develop bishops
□ Castle (within 8-10 moves)
□ Connect rooks
□ Don't move queen early
□ Don't move same piece twice
```

## 🔧 Troubleshooting

### Extension Not Loading
```
1. Check Developer mode is enabled
2. Reload extension from chrome://extensions/
3. Check console for errors (F12)
```

### Game Not Detected
```
1. Make sure game modal appeared
2. Refresh Chess.com page
3. Try analyzing another game
4. Check content script loaded (F12 → Console)
```

### Analysis Seems Wrong
```
Remember: This is heuristic-based analysis, not engine-based.
It catches common mistakes but may miss complex tactics.
Use it as a learning guide, not absolute truth.
```
